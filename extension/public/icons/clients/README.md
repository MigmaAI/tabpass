# Client icon sources

These assets are bundled with the extension; the UI does not fetch provider artwork at runtime.

- `claude.svg`, `chatgpt.svg`, `cursor.png`, `codex.png`, `gemini.png`, `windsurf.svg`, and `copilot.svg` were copied from Migma's existing frontend brand assets in `f/migma/public/images/`.
- `vscode.svg` was copied from the existing Migma Docs logo set in `migma-docs/images/logos/`.

Provider names and marks belong to their respective owners.
