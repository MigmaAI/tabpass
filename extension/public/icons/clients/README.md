# Client icon sources

These assets are bundled with the extension; the UI does not fetch provider artwork at runtime.

- `claude.svg`, `chatgpt.svg`, `cursor.png`, `codex.png`, `gemini.png`, `windsurf.svg`, and `copilot.svg` were copied from Migma's existing frontend brand assets in `f/migma/public/images/`.
- `vscode.svg` was copied from the existing Migma Docs logo set in `migma-docs/images/logos/`.
- `cline.svg`, `goose.svg`, `lmstudio.svg`, `opencode.svg`, `perplexity.svg`, and `mistral.svg` are from [`@lobehub/icons-static-svg` 1.95.1](https://www.npmjs.com/package/@lobehub/icons-static-svg), published under the MIT license. `mistral.svg` represents Mistral's Le Chat.
- `zed.svg`, `warp.svg`, and `jetbrains.svg` are from [`simple-icons` 16.35.0](https://www.npmjs.com/package/simple-icons), published under CC0-1.0. The Zed filename was shortened from `zedindustries.svg`.

Provider names and marks belong to their respective owners.
